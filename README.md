# Gentleman Barbershop Tbilisi — დემო საიტი

ერთგვერდიანი საიტი თბილისური ბარბერშოპისთვის (საბურთალო, ბიძინა კვერნაძის 13) + მარტივი ადმინ პანელი.
ეს **დემო ვერსიაა** მფლობელებისთვის საჩვენებლად: ფასები და ფოტოები ნიმუშია. საიტი: Gridline.

Live: https://tikadzenika-bit.github.io/gentleman-barbershop/ · admin: https://tikadzenika-bit.github.io/gentleman-barbershop/admin.html

## როგორ გავხსნა

**ყველაზე მარტივად:** ორჯერ დააწკაპუნე `index.html`-ზე — იხსნება ბრაუზერში, build არ სჭირდება.

**ლოკალური სერვერით** (უფრო ახლოსაა ნამდვილ ჰოსტინგთან):

```bash
python -m http.server 8350
```

შემდეგ გახსენი `http://localhost:8350/` (საიტი) და `http://localhost:8350/admin.html` (ადმინი).

ენა ირთვება ზედა მენიუდან (KA / EN / RU) ან ბმულით: `index.html?lang=en`, `?lang=ru`.

**ტელეფონზე** `localhost` არ იხსნება — ტელეფონზე სანახავად საიტი GitHub Pages-ზე უნდა აიტვირთოს (იხ. ქვემოთ).

## GitHub Pages-ზე ატვირთვა

1. ატვირთე საქაღალდის შიგთავსი რეპოზიტორიაში (`index.html` ძირში უნდა იყოს). `ADMIN-PASSWORD.txt` `.gitignore`-შია და არ აიტვირთება.
2. Settings → Pages → Branch: `main`, folder: `/ (root)`.
3. გაშვების შემდეგ `index.html`-ში `og:image`-ში ჩაწერე **სრული მისამართი** (WhatsApp-ს და სოც. ქსელებს აბსოლუტური ბმული სჭირდებათ),
   მაგ. `https://<user>.github.io/<repo>/assets/img/og.jpg`, და დაამატე `<link rel="canonical">` და `og:url`.
   მანამდე WhatsApp-ით გაგზავნილ ბმულს ლამაზი სურათი **არ გამოუჩნდება**.

### რეალურ ბექენდზე გადასვლა

მთელი შინაარსი და ჯავშნები ერთ JSON ობიექტშია (იხ. `DEFAULT_DATA` `assets/js/data.js`-ში; იგივე ფორმატს იძლევა „ექსპორტი JSON“).
საიტი და ადმინი მონაცემებს მხოლოდ `TBStore.load()` / `TBStore.save()` / `TBStore.onExternalChange()`-ით ეხება,
ამიტომ Supabase-ზე ან Firebase-ზე გადასასვლელად საკმარისია ამ სამი ფუნქციის ჩანაცვლება
(და პაროლის შემოწმების გადატანა სერვერზე — Supabase Auth / Firebase Auth). ფოტოები ამ დროს Storage-ში უნდა აიტვირთოს:
ახლა ადმინიდან ატვირთული ფოტო მცირდება და ინახება პირდაპირ JSON-ში, რასაც ბრაუზერის ~5 MB ლიმიტი აქვს.

localStorage-ის გასაღებები: `gentleman.data.v1`, `gentleman.lang`; ადმინის სესია — `gentleman.admin` (sessionStorage).
